FindReplace Pro Help

What is FindReplace Pro?

Bulk find & replace tool with publishing workflow. Search your site content and publish changes.

Features

  • Content Search - Find text in all content, page metadata, section metadata, or block content
  • Element Discovery - Find pages containing specific CSS selectors (leave search term empty)
  • Bulk Replace - Select multiple files and replace content
  • Publishing - Preview, publish, or unpublish selected files

How to Use

1
Search

Enter search term and optionally set base path. For element discovery, use Custom Selector and leave search term empty.

2
Review

Click "Scan Files" to see results. Select files you want to modify.

3
Execute

Use "Execute Replace" to modify content, or choose Preview/Publish/Unpublish for publishing operations.
